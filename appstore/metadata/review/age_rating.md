# Age rating questionnaire

The whole subject of the app is tasting wine and spirits, so answer the alcohol
question honestly — under-declaring is a common cause of rejection.

| Question | Answer |
| --- | --- |
| Cartoon or Fantasy Violence | None |
| Realistic Violence | None |
| Prolonged Graphic or Sadistic Realistic Violence | None |
| Profanity or Crude Humor | None |
| Mature/Suggestive Themes | None |
| Horror/Fear Themes | None |
| Medical/Treatment Information | None |
| **Alcohol, Tobacco, or Drug Use or References** | **Frequent/Intense** |
| Simulated Gambling | None |
| Sexual Content or Nudity | None |
| Graphic Sexual Content and Nudity | None |
| Contests | None (the points are a parlour game, no prizes or entry) |
| Unrestricted Web Access | No |
| Gambling with real money | No |
| Made for Kids | No |

Expected result: **17+** (Apple's rating for frequent alcohol references).

Guideline 1.4.3 — apps that encourage excessive consumption — is not an issue
for a structured tasting app. Keep it that way: never add features that gamify
drinking volume or speed.
